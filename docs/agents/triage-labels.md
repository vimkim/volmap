# Triage labels

Canonical roles map directly to local Status values:

| Role | Status |
| --- | --- |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

These are triage roles; Wayfinder claim/resolution state is separate.
